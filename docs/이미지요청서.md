AI 생성 기준 브리프입니다. 툴은 편하신 걸로 쓰시면 되고, 아래 프롬프트는 초안이라 결과 보면서 고쳐주세요.

## 2. 16장 공통 규칙 (가장 중요)

16장이 **한 세트로 보여야** 합니다. 결과를 공유받은 친구가 "나는 뭐 나왔지?" 하고 다른 콤이 궁금해지게 만드는 게 목적이에요.

- **화풍 통일:** 첫 장을 뽑고 마음에 들면, 그 이미지를 스타일 레퍼런스로 걸고 나머지 15장을 뽑아주세요.
- **구도 통일:** 남자 캐릭터 1명, 상반신(허리 위), 정면~3/4 각도, 화면 가운데.
- **잘리는 영역:** 이미지가 정사각형·가로형으로도 잘려 쓰입니다. **얼굴과 어깨가 세로 가운데 1080×1080 안에** 들어오게, 머리 위는 약간 여유.
- **배경:** 아래 표의 콤별 색 단색(또는 아주 옅은 그라데이션). 배경에 소품·글자 넣지 않기.
- **글자 금지:** 이미지 안에 글자·로고·워터마크 없음 (제목은 코드가 얹습니다).
- **노출 금지:** 상의 탈의, 선정적 포즈, 과한 노출 없음. 근육콤도 옷 입은 채로 체격이 드러나는 정도. 인외·퍼리도 동일. (광고 심사 + 미성년 유입 때문)
- **저작권:** 기존 애니·웹툰·게임 캐릭터를 닮게 만들지 않기. 특정 작품명·작가명 프롬프트 금지.
- **톤:** 웃기고 살짝 과장된 쪽. "이게 내 취향이라고?" 싶은 약간의 민망함이 포인트.

### 공통 스타일 프롬프트 (모든 장 앞에 붙이기)
```
single male character, upper body portrait, centered, 3/4 view, clean korean webtoon illustration style, crisp line art, soft cel shading, expressive face, solid flat background color {HEX}, no text, no watermark, fully clothed, safe for work, 4:5 aspect ratio
```

## 4. 키비주얼 · 로고
- **키비주얼:** 16명 캐릭터가 작게 모여 있는 단체컷(얼굴 위주) 또는 문 뒤에서 여러 콤이 빼꼼 보는 구도. 가운데 위쪽에 제목이 들어갈 빈 공간 남기기. 16장 완성 후 그 캐릭터들로 만드는 게 좋습니다.
- **가로판(1200×630):** 같은 이미지를 가로로 재구성. 왼쪽 절반은 비워서 글자 자리.
- **로고:** 브랜드명 확정 후 요청드릴게요 (현재 가제 "콤 테스트").

## 5. 납품
- 파일명 규칙대로 PNG로 한 폴더에 모아서 전달.
- 먼저 **음침콤·퍼리콤·오지콤 3장**만 뽑아서 톤 확인 받고 나머지 진행하면 재작업이 줄어듭니다.
- 이미지 오기 전까지 사이트는 콤별 색 + 글자 카드로 먼저 만들어 둡니다. 나중에 파일만 교체하면 됩니다.
