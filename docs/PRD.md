# 콤 테스트 PRD v1

- 작성: 2026-09-30
- 상태: 초안 (문항·채점은 `문항_채점표.md`, 이미지는 `이미지요청서.md`)
- 사이트명: **나는 무슨 콤일까?** / 부제 **~숨겨진 취향을 알려드립니다~**
- 디자인: 로맨스(순정) 만화책 표지 톤. 캐릭터 없이 분위기만 — 핑크·장미색 레터링(흰 테두리), 필기체 영문 부제, ✦ 반짝이, 하늘색 꽃 장식, 스크린톤 점, 만화 칸 테두리. 폰트: Jua(제목), Great Vibes(영문), Pretendard(본문)

## 1. 한 줄 정의
64문항으로 "당신이 절대 인정하고 싶지 않았던 취향"을 **16콤 × 보조콤 조합**으로 폭로하는 모바일 웹 테스트. 인스타 스토리 공유로 퍼지고 광고로 번다.

## 2. 포지셔닝
- "여자들의 이상형 검사"가 아니라 **"여자들의 콤 취향을 폭로하는 검사"**.
- 결과 화면 카피는 "당신의 이상형은?"이 아니라 **"당신이 절대 인정하고 싶지 않았던 취향은?"**
- 오락용 테스트. "과학적", "무의식 분석" 같은 표현은 쓰지 않는다 (문항 대부분이 대놓고 묻는 방식이라 사실과 다름).

## 3. 타깃 · 지표
- 타깃: 인스타 유입 여성 10대 후반~30대, 모바일 거의 전부.
- 지표
  - 시작 → 완료율 **60% 이상** (64문항이라 이탈이 최대 리스크)
  - 결과 → 공유 클릭률 **15% 이상**
  - 페이지뷰당 광고 수익 (광고 붙인 뒤)

## 4. 화면

### 4-1. 랜딩 `/`
- 키비주얼, 메인 카피 "당신이 절대 인정하고 싶지 않았던 취향은?"
- 부제: "64문항 · 약 4분 · 16가지 콤"
- 시작 버튼, 콤 도감 링크
- 하단 광고 자리 1

### 4-2. 테스트 `/test`
- 1화면 1문항. 5개 버튼(전혀 아니다 ~ 매우 그렇다) 세로 배치, 누르면 자동으로 다음 문항.
- 상단 진행바 + "12 / 64".
- 뒤로가기(이전 문항 수정 가능).
- 16·32·48번째 지점에 한 줄 응원 멘트 ("벌써 절반. 여기까지 온 걸 보니 뭔가 있다").
- 안내 문구: "현실이든 픽션이든 상관없이, 끌리는 대로 답해주세요."
- 새로고침해도 진행 상태 유지(브라우저에 임시 저장).
- **광고 없음** — 버튼 근처 광고는 오클릭 유도로 광고 정책 위반 위험.

### 4-3. 분석 중
- "취향 분석 중…" 2~3초 연출. 광고 자리 1.

### 4-4. 결과 `/r/[주콤]-[보조콤]`
위에서부터:
1. (링크로 들어온 사람에게만) "나도 해보기" 버튼
2. 주콤 캐릭터 이미지
3. 조합 제목: "당신의 콤 유형은 「음침한 집착남」"
4. 주콤 태그라인: "구석에서 혼자 있는 남자를 자꾸 찾는 사람"
5. 핵심 콤 / 보조 콤 배지
6. 광고 자리 1
7. 주콤 본문 (2~3문단)
8. 보조콤 문단 ("여기에 ○○콤이 섞이면…")
9. 16콤 막대 프로필 (내 점수 전체)
10. 궁합: 잘 맞는 콤 / 안 맞는 콤
11. 집착·광기가 주·보조에 있으면: "※ 현실 연애에선 이건 위험 신호입니다" 한 줄
12. 공유 버튼: 스토리 이미지 저장, 링크 복사, 카카오톡 공유
13. 다시하기, 콤 도감 보기
14. 광고 자리 1~2

결과 URL에는 주/보조 콤만 들어가고, 16콤 막대 점수는 본인 화면에만 보인다 (링크로 들어온 사람은 막대 대신 "나도 해보기").

### 4-5. 철벽형 결과 `/r/cheolbyeok`
주콤 점수 6점 이하일 때. "아무한테도 안 끌리는 게 아니라, 아직 안 들킨 것". 공유 흐름은 동일.

### 4-6. 콤 도감 `/types`, `/types/[콤]`
16콤 소개 페이지. 광고 심사용 콘텐츠 볼륨 + 체류시간 확보.

### 4-7. 필수 페이지
- `/privacy` 개인정보처리방침 (광고·분석 쿠키 고지)
- `/about` 소개 · 문의 이메일
- 광고 네트워크 승인 조건이라 v1에 포함.

## 5. 기능 요구사항

| 기능 | 내용 |
|---|---|
| 채점 | `문항_채점표.md` 규칙 그대로. 전부 브라우저에서 계산, 서버·DB 없음 |
| 문항 섞기 | 사용자마다 무작위, 같은 콤 연속 금지 |
| 링크 미리보기 | 결과 URL마다 1200×630 미리보기 이미지 자동 생성 (240조합 + 철벽형) |
| 스토리 이미지 | 1080×1920 이미지 생성 → 저장 버튼 (인스타 스토리 업로드용) |
| 카카오톡 공유 | 카카오 개발자 앱 키 필요 (사용자 발급) |
| 이벤트 수집 | PostHog (션 요청). 이벤트 목록은 아래 5-1 |
| 광고 | 광고 자리(슬롯)만 코드에 만들어 둠. 네트워크 미정 |

### 5-1. PostHog 이벤트
환경변수 `NEXT_PUBLIC_POSTHOG_KEY`가 있을 때만 전송. 페이지뷰·페이지이탈은 자동 수집.

| 이벤트 | 언제 | 속성 |
|---|---|---|
| `test_started` | 테스트 화면 진입 | `resumed` (이어하기 여부) |
| `test_progress` | 8문항마다 | `answered` |
| `test_abandoned` | 중간에 페이지 이탈 | `answered` (어디서 나갔나) |
| `test_completed` | 64문항 완료 | `result`, `main`, `sub`, `duration_sec`, `scores`(16콤 점수) |
| `result_viewed` | 결과 페이지 | `result`, `own`(본인 결과인지 공유 링크 방문인지) |
| `share_clicked` | 공유 버튼 | `result`, `method`(story_image / link_copy / native_share) |
| `retake_clicked` | 다시 하기 | `result` |
| `try_cta_clicked` | 공유 링크 방문자가 "나도 해보기" | `result` |
| `types_viewed` | 콤 도감 상세 | `kom` |

- 완료율 = `test_completed` / `test_started`, 이탈 구간 = `test_abandoned.answered` 분포
- 바이럴 계수 = `try_cta_clicked` / `result_viewed(own=true)`
- 보편 취향 보정(v1.1) = `test_completed.scores` 1,000건의 콤별 평균·표준편차
